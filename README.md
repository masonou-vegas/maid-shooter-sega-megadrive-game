# Maid Shooter

Maid Shooter — Sega Mega Drive (Genesis) homebrew shooter.

This repository contains the distribution/build for the game (no source included here). If you plan to add the .bin build, put it in the `builds/` directory or attach it to a Release.

## Contents

- assets/ — game assets (sprites, samples, etc.)
- docs/ — design notes, manual, or changelog
- builds/ — compiled .bin / distribution files

## Running

You can run the .bin with a Mega Drive / Genesis emulator (e.g., Kega Fusion, Genesis Plus GX) or flash it to a compatible cartridge/flash cart.
